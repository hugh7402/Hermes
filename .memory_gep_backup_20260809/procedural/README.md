# Procedural Memory

**How to do things.**

Workflows, patterns, processes you use repeatedly.

## Format

File: `process-name.md`

Example:
```markdown
# Provider Switch

**When to use:** User asks to change AI model/provider

**Steps:**
1. Check current config via hermes config
2. Find correct model name on target provider
3. hermes config set model.provider/base_url/default/api_key
4. Restart gateway from terminal
```

## When to add
- Repeatable workflow
- Step-by-step process
