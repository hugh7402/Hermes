# Episodic Memory

**What happened, when.**

Time-based event logs. Chronological context.

## Format

File: `YYYY-MM-DD.md`

Example:
```markdown
# 2026-07-09

## Switched to SiliconFlow provider
- Changed from DeepSeek official API to SiliconFlow
- Faster response, no peak-hour pricing
```

## When to add
- Daily summary of events
- Significant moments
- Time-sensitive context
