# Semantic Memory

**What I know.**

Facts, concepts, knowledge. Distilled learnings.

## Format

File: `topic-name.md`

Example:
```markdown
# Cocoloop Hub

**What it is:** Public skill marketplace at hub.cocoloop.cn

**API:** api.cocoloop.cn/api/v1/store/skills

**Key facts:**
- 7000+ skills available
- Skills can be adapted for Hermes
```

## When to add
- Learned something new about a topic
- Need to remember facts
