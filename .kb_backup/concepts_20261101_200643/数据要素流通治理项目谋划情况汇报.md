# 数据要素流通治理项目谋划情况汇报

---

数据要素流通治理项目谋划情况汇报
自州委州委“一揽子政策”项目谋划专班成立以来，我局聚焦国家数据要素市场化改革导向，将数据要素流通项目谋划与全州数字化建设、数字经济紧密结合，牵头谋划“延边州数据要素流通项目”，现将该项目相关情况汇报如下：
一、项目基本情况
（一）延边州数据要素流通建设
1. 一枢纽：延边州数据流通枢纽作为全州数据要素流通的核心承载（物理载体与虚拟空间），承担政务数据、产业数据、稳边固防相关数据及珲春互市贸易数据的集中存储、算力支撑与流通枢纽功能，为后续数据安全治理、合规流通提供基础支撑。
2. 三核心平台：数据资源一体化平台，负责数据的汇聚、存储、清洗、标注、脱敏、标准化等，形成高质量的数据资源池。数据流通交易服务平台，提供数据产品登记、评估定价、供需撮合、在线交易、清结算、争议解决等服务。数据应用赋能平台，提供数据分析工具、算法模型、API接口、沙箱环境等，支持数据开发者进行应用创新。
3. N中心：根据发展需要设立若干专业中心。数据治理与标准中心负责制定数据标准、质量规范、安全协议等。数据资产评估中心探索数据资产价值评估方法与模型。数据安全与隐私计算中心研发和应用数据安全、隐私保护技术。数据要素产业孵化中心为数据创新创业企业提供孵化服务。数据才培训中心培养数据相关专业人才。
4. 多场景：聚焦延吉特色和优势，打造多个典型数据应用场景，如智慧农业、智能制造、现代物流、普惠金融、智慧文旅、城市治理等。
（三）投资规模与资金来源
项目计划总投资 1 亿元，资金来源为企业自筹和申请中央预算内资金、超长期国债、地方政府专项债，同步对接吉林省数据资产全过程管理试点专项支持资金。
二、项目背景
2024年国家数据局发布《可信数据空间发展行动计划（2024—2028 年）》首次系统布局，核心是通过技术架构和制度设计融合构建“数据可用不可见、可控可追溯”的分布式流通环境，确保数据保留在本地且所有者主权不受损；截至2025年已启动63个试点，拓展900余个应用场景，覆盖政务、金融、医疗、能源等领域，依托区块链、隐私计算等技术实现可信管控、资源交互与价值共创能力，形成政府引导的中国特色路径，也计划2028年建成100个以上空间，为全国一体化数据市场构建提供关键支撑，破解数据共享中“不敢给、不能用”的痛点，助力数字经济发展。
三、谋划思路
围绕数据要素“安全流通、价值释放”核心目标，将数据要素流通平台建设与文旅、人参、黄牛等特色产业及城市治理需求深度结合，通过“制度 + 技术”双轮驱动，破解数据孤岛、流通合规、价值评估等难题，打造东北跨境数据要素流通标杆项目。力求通过项目建设补齐我州数据基础设施短板，推动数据资源向资产转化，壮大数字产业规模，助力全州经济社会从“资源依赖”向“数字驱动”转型。
四、我州的优势与不足
（一）优势
政策优势：吉林延吉-长白重点开发开放实验区获批，政策明确“大力发展大数据等新兴产业、完善沿边信息基础设施”为数据要素流通项目提供政策背书。
行业需求优势：文旅、人参、黄牛等优势产业，及延吉卷烟厂、延边大学、敖东药业等企业/机构，对算力、云资源及数据开放共享需求强烈，可通过数据要素流通创新业务模式、优化产业流程，为项目提供丰富应用场景。
跨境贸易优势：珲春互市贸易平台作为我州面向东北亚的重要跨境贸易载体，已汇聚大量边贸交易数据、物流数据及商户数据，为数据要素流通提供了优质的跨境数据资源储备，可直接对接平台实现边贸数据“可用不可见”共享，赋能跨境贸易数字化升级。
（二）不足
数据基础设施不完善：现有数据中心规模有限，难以支撑大规模数据存储与分析；对5G、边缘计算、人工智能等新兴技术支持不足，无法满足数据要素流通对高效算力、低时延传输的需求。
缺乏统一数据汇聚与流通平台：长期无统一的数据汇聚及智慧城市管理平台，各部门数据系统独立运行，数据孤岛现象严重，跨部门、跨领域数据流通缺乏有效载体，数据要素价值难以释放。
制度体系与工作机制缺失：未形成适配我州实际的数据要素流通制度体系，数据确权、价值评估、安全合规等规则不明确，增加数据资产化过程中的法律风险与不确定性。
五、项目意义
一是服务国家战略，打造沿边数字标杆。项目积极响应国家关于构建数据基础制度、发展数字经济的战略部署，是落实《可信数据空间发展行动计划》在沿边地区的具体实践。通过探索跨境数据流通、稳边固防数据应用等特色路径，旨在形成可复制、可推广的“延边经验”。
二是赋能产业升级，培育经济新动能。项目紧扣我州文旅、人参、黄牛等特色优势产业，通过数据要素的深度赋能，能够驱动产业向智能化、精准化、高端化转型，从而催生新业态、新模式，壮大数字产业规模，是实现我州从“资源依赖”向“数字驱动”转型的关键抓手。
三是提升治理效能，保障边疆安全稳定。项目将稳边固防数据纳入流通治理体系，通过对相关数据的融合分析与应用，能够显著提升边境管控、应急指挥、社会治理的精准性和效率，为维护国家安全和边疆稳定提供强大的数字支撑。同时，数据驱动的城市治理也将改善民生服务，提升城市运行效率和居民幸福感。
四是破解数据瓶颈，夯实数字基建底座。项目通过建设统一的数据枢纽与核心平台，将有效破解长期困扰我州的数据孤岛、基础设施薄弱、制度体系缺失等核心难题，为全州数据资源的汇聚、治理、共享与价值释放提供统一的载体和规范的遵循，补齐我州数字经济发展的关键短板。
五是激活数据价值，创新商业营利模式。项目通过构建市场化的流通交易服务平台和数据资产评估体系，能够有效推动政务数据、企业数据等从资源向资产转化，探索数据资产入表，并衍生出算力服务、数据产品、跨境服务等多种营利模式，为项目的可持续运营和价值创造开辟广阔空间。
六、营利模式
遵循“基础服务+增值运营+生态共建”逻辑，构建多元化数据要素流通盈利体系。
算力服务分层收费：面向政府、企业、高校提供基础算力租赁；为文旅、农业等领域提供定制化算力。
数据要素市场化运营：依托平台推动政务、文旅等数据资产入表，开发“人参产业链图谱”等特色数据产品；向企业提供标准化数据API接口，按订阅制收费。
生态共建与政策红利：申请中央预算、专项债等政策性资金，降低资金成本；通过算力招商吸引科技企业入驻，按企业营收取生态服务费；与延边大学共建实训基地，开展数据分析师认证培训。
跨境特色数据服务：依托区位优势，提供中朝俄跨境数据处理、跨境电商数据分析服务，拓展数据要素流通的边疆特色盈利场景。
