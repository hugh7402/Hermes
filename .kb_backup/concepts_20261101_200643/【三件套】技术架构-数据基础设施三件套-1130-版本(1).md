三件套整体技术架构
采用分布式高可用设计，支持高可靠和弹性扩容能力。使用业界先进的技术框架和微服务等理念构建各个功能模块，结合区块链技术满足可信资源空间体系建设。
前端架构：采用VUE+WebPack+ANTV，构建定制化框架平台，底层主要包括5大核心模块，分别为服务基类、消息总线、事务服务、状态管理和日志管理，组件间的通信采用VUEX+Event Dispachtcher的方式来实现，使平台的数据逻辑更加清晰，更好的实现组件化、模块化开发。
可信服务层：
网关方面，采用 ShenYu Gateway  网关作为平台统一入口，提供高并发场景的处理能力，实现多协议（HTTP/WebSocket/TCP）的请求代理能力和多种身份认证的访问控制能力，保障服务可靠性和可用性。
核心服务，包括区域功能、流通利用和连接器三大核心服务，实现国家基础设施互通互通接口标准，整体采用SpringBoot + SpringCloud + Mybatis 分布式服务框架，提供高性能透明化RPC远程调用和提供SOA服务治理能力，实现应用各个层之间解耦合。通过与区块链（BaaS）原生融合，使用可信存证的方式实现事后全链路可审计、可追溯。
数据沙箱：基于容器化与虚拟化强隔离技术，以 JupyterHub、SQL IDE 为交互载体，集成代码托管、调度编排及多框架算法库能力，实现 “数据可用不可见” 的数据隔离保护；支持多租户协同开发、打造安全高效的全栈式数据开发分析环境，筑牢数据的安全流通。
隐私计算：凭借 AgentCluster 集群管控、Fate 联邦学习等组件，提供跨域多方协同计算能力，包含联合建模、联合预测、联合计算、联合查询，构建 “数据可用不可见” 的安全协作架构，支持计算过程中基于各类加密协议，仅传递密态中间数据即可完成协同计算；并支持细粒度数据访问权限控制。
基础组件：依托自主研发的技术底座，整合了 ExposAdmin 用户中心、ExposWorkflow 工单服务、ExposLog 日志服务等全栈基础组件，覆盖身份管控、流程协同、资源管理等核心基础能力。为上层业务提供了自主可控、稳定可靠的底层支撑，夯实了全链路技术自主的基座优势。
区块链：采用 Bass 平台 和 DID 提供综合分布式账本、密码学技术、共识算法、智能合约等能力，实现数据共享、优化业务流程、降低运营成本、提升协同效率、建设可信体系。
数据存储：系统业务数据存储兼容国产通用数据库，支持文件、对象、日志、消息队列等多类型数据存储形态；采用 Doris 高性能 MPP 数据库架构，通过资源隔离机制实现数据资源的独立管控与高效调度。
基础设施：为快速适应安全可靠环境适配，基于Docker/K8S容器化技术构建云原生系统，最大程度发挥云计算快速迭代、灵活弹性的优点，加速软件开发和交付效能，实现资源的隔离、快速部署。
数据安全管控：系统严格遵守保密测评要求，对主机、用户、数据库、应用、安全设备进行日志采集和审计，细粒度分析用户异常行为，挖掘潜在风险，同时，可以通过态势感知总览安全现状和趋势，为安全保障提供决策依据。

 Expos DID  分布式身份服务
采用分布式高可用设计，具备高可靠与弹性扩容能力，以业界先进技术框架及微服务理念构建各功能模块，并融合区块链技术，支撑可信资源空间体系建设。
前端架构：基于 VUE 可视化开发框架、Webpack/Vite 构建工具、ANTV/Plumb 可视化组件库搭建定制化平台，搭配 TailWind 样式框架、Pinia 状态管理工具、SSE 服务推送协议、TypeScript 编程语言及 Axios 网络请求库，通过组件化、模块化开发梳理数据逻辑，保障前端交互的高效灵活。
网关服务：以 ShenYu Gateway 为统一入口，提供 HTTP/WebSocket/TCP 多协议请求代理能力，结合 Sentinel/Hystrix 熔断限流、OAuth2/JWT/WT 身份认证及 LoggingKafka/LoggingES 日志记录机制，保障服务可靠性和可用性。
服务层：涵盖三大核心模块 DcupAdmin 数据流通管理，承担数据产品、数据资源、连接器等业务的全流程管控，是数据流通环节的核心支撑层；DcupDevlopment 数据利用管理，具备数据采集和数据服务并联动数据沙箱与隐私计算的能力，承担数据计算环节的协同调度职责； DcupAPI 集成对接服务，既适配基础设施互联互通标准，又依托 SpringBoot+SpringCloud+Mybatis 分布式框架实现高性能 RPC 远程调用与 SOA 服务治理，同时通过与区块链技术的原生融合，构建业务全链路的可审计、可追溯能力。
数据沙箱：基于容器化强隔离技术，以 JupyterHub、SQL IDE 为载体，集成代码托管、调度编排及算法库能力，实现 “数据可用不可见” 的安全开发环境；
隐私计算：通过 AgentCluster 集群管控、Fate 联邦学习等组件，构建 “数据可用不可见” 的跨域协同计算架构，支持加密协议下的联合操作与细粒度权限控制。
基础支撑层：依托自研技术底座，整合 ExposAdmin 用户中心、ExposWorkflow 工单服务等全栈组件，搭配 Nacos 服务配置、Expos DID 分布式身份、BaaS 区块链等能力，提供自主可控的底层支撑；
数据存储层：兼容国产数据库，支持文件、对象、日志等多类型存储，通过 Doris/Greenplum MPP 架构实现资源隔离管控；
基础设施层：基于 Docker/K8S 构建云原生系统，适配信创环境并结合网络安全防护，发挥云计算弹性优势加速交付。
