## 四、原型能力（对照采购需求 215 / 216）

| 条款 | 要求 | 原型落点 |
|---|---|---|
| **215-1** ▲ | 注册新增目录（**直接文件导入**），目录含 7 类属性要素，并审核发布 | **基础标识属性**（目录名称、数据提供单位、数据摘要、目录来源）、**数据特征属性**（数据来源系统、所属分类、数据所属领域…）、范围界定、共享开放、事项业务关联、发布管理、数据项，共 7 组 56 字段 + 要素文件导入 → 一级审核 → 状态「已发布」 |

## 五、数据口径（技术评委可能追问）

五项数字**算术自洽**，全部由数据集真实算出，非写死：

```
归集数据总量 1,000 条
  − 完全重复   32 条（去重规则剔除）
  = 去重后数据量 968 条
  = 清洗数据总量 968 条
  = 优质数据 902 条 + 问题数据 66 条        ← 902 + 66 = 968 ✅

问题数据 66 条 = 过滤 12 + 转换 28 + 保留原值 18 + 去重 8
问题清单合计 98 条 = 66（治理识别）+ 32（去重剔除）
```

**规则是真的在跑，不是标数字好看**（已用脚本逐条验证）：

| 验证项 | 结果 |
|---|---|
| 过滤 12 条：GB 11643 校验码是否真的不通过 | 12/12 确实不通过 ✅ |
| 过滤 12 条：是否只差校验码（前 17 位应一致） | 12/12 前 17 位完全一致 ✅ |
| 其余 988 行：校验码是否真的通过 | 988/988 通过 ✅ |
| 去重 8 条：自然人唯一标识是否真的重复 | 8/8 确实重复 ✅ |
| 转换 28 条：原始值真的不规范、权威值真的合规 | 28/28 ✅ |
| 保留原值 18 条：姓名真的与权威源不一致 | 18/18 ✅ |
| 完全重复 32 条：全字段签名确实重复 | 32 条 ✅ |
| 权威源表 968 行号码合法性 + 出生日期段合法性 | 0 个非法 ✅ |

> 现场可让评委任意抽查：数据侧的身份证件号码确实算不过 GB 11643 加权校验；保留原值的记录确实与权威源姓名不符。

## 八、已知边界

- 本原型是**高保真交互原型**，非生产系统。数据为内存态，刷新页面即归零（可用【重置数据】主动重置）。
- 审核为**一级审核**（按本次要求合并）。真实系统支持配置多级审核流程，可按需求扩展。
- 界面按业务人员易用方向设计，回应初步设计中对既有系统"交互界面偏技术化、对非技术背景业务人员不友好"的批评。
- 底部功能区备案号/标识码用 `XXXXXXXX` 占位，**未编造任何真实备案号**。
- 配色取自实测（中国政府网 `#015293` / `#2691e2` / `#d9000d`），符合国办发〔2017〕47号"总色调不宜超过3种"；状态语义色（绿/橙/红）按无障碍要求**不靠颜色单传信息**（均配文字与图标）。
