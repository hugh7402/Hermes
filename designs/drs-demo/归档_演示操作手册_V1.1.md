## 一、演示前准备（2 分钟）

**1. 打开原型**
- 双击 **`四川一体化数据资源管理系统_V1.1.html`**
- **用 Chrome 打开**（地址栏会是 `file:///...`）
- 单文件自包含：**断网也能跑**，无任何外部依赖
- 建议 `F11` 全屏，浏览器缩放 100%

**2. 准备上传用文件**（演示到第 5 步要用）
- **`演示数据/待归集数据_自然人基本登记信息.csv`**（1000 行）——放桌面便于快速选择

**3. 重置到初始状态**
- 进左菜单 **【治理成效总览】** → 右上角 **【重置数据】** → 确定
- 或直接重新打开一次文件

**4. 讲前必说的两句话**
> "本系统按省级一体化数据资源管理平台架构搭建，演示数据为脱敏后的样例数据。"
> "以下完整演示数据资源目录编目、数据归集与数据治理的全流程。"

**5. 姓名脱敏说明**（评委若问）
> "界面中人员姓名按数据安全要求统一脱敏显示（如「李**」），系统内实际保存完整信息。"

**6. 两个系统与切换方式**（演示前务必知道）
- 本原型由**两个系统**组成：
  - **数据目录管理系统** —— 政务数据目录的编目、审核与发布；
  - **数据归集管理系统** —— 数据归集与数据治理。
- **切换方式：顶部第二行「系统：」导航栏直接点系统名**，当前系统带「当前」标记。**没有专门的"切换系统"按钮**，评委问起就说"按平台导航切换"。
- 顶部共**四行**：平台栏 → **系统导航栏** → 模块导航 → 业务流程进度条。
- **进度条随系统自动切换**：数据目录管理系统显示「**编目流程**」（编目填报 → 审核发布 → 已发布）；数据归集管理系统显示「**归集治理流程**」（归集审批 → 自动建表 → 归集已实施 → 治理规则 → 治理完成）。
- 界脚右下角显示**版本 V1.1**，评审核对版本时可直接指给他看。

## 三、调试开关（Ctrl+D）

**给非技术同事用，或你自己发现问题时用。核心是「点一下就能复制」，不用追着元素跑。**

| 操作 | 效果 |
|---|---|
| 按 **`Ctrl + D`**（Mac 用 `Cmd + D`） | 开启调试模式，右下角浮出调试面板 |
| 鼠标移到任意元素上 | 该元素**红框高亮**，面板显示：屏号、元素标签、id、class、**完整选择器**、元素文本 |
| **点击该元素** | ★ **立即锁定并自动复制**，元素转为**琥珀色**。点击**不会触发系统功能**（不会误翻页） |
| 锁定后鼠标随便移 | **面板信息与被复制内容都不再变化** —— 可以从容去点【复制】或按 `C` 再复制一次 |
| 按 **`C`** | 复制当前（或已锁定）元素的定位信息，**全程不用碰鼠标** |
| 按 **`Esc`** | 解锁，恢复跟随鼠标 |
| 点面板右上角 **【复制】** | 复制已锁定元素的信息（锁定后鼠标移过去点，内容不会变） |
| 再按 **`Ctrl + D`** | 关闭调试模式，恢复正常外观 |

**复制到的内容长这样**（三行，可直接粘给我）：

```
屏 s7c｜系统 govern｜元素 th｜id (无)｜class (无)
选择器 table#tbl-clean > thead > tr > th:nth-of-type(2)
文本 问题类型
```

**反馈问题推荐做法**：开调试模式 → **点一下出问题的元素**（自动复制）→ 直接粘贴给我。零歧义，我不用猜。

> 如果剪贴板被浏览器限制（file:// 下偶尔发生），面板下方会浮出一个只读文本框，里面的内容可以手动 `Ctrl+C` 复制。

> 演示前请确认调试模式是**关闭**状态（默认关闭，刷新页面也会关闭）。

## 四、评委可能追问 & 应对

| 追问 | 应对 |
|---|---|
| **"数据是真实的吗？"** | "是脱敏后的样例数据。但**规则是真的在跑**：身份证件号码用 GB 11643-1999 加权算法逐位校验，**12 条过滤数据的校验码确实算不过**；8 条去重数据的唯一标识确实重复；18 条保留原值数据的姓名确实与权威源不一致——现场可以任意抽查。" |
| **"为什么问题数据有 66 条？"** | "样例数据中注入了四类质量问题。生产环境问题数据可能更多，系统按同一套规则识别并输出明细，可导出给数源单位整改。" |
| **"问题数据 66 条、清单却 98 条？"** | "问题清单共 98 条 = 治理阶段识别 66 条（过滤12+转换28+保留原值18+去重8）+ 去重规则剔除的 32 条完全重复。页面五项数字用的是 66 条口径，与『优质 902 + 问题 66 = 清洗 968』一致。" |
| **"审核只有一级吗？"** | "本次按需求实现单级审核后直接发布。系统支持配置多级审核流程（初审/复审/终审），可按各部门管理要求灵活设定。" |
| **"能否现场改配置再看结果？"** | "可以。" → 回到治理规则配置，把异常策略切成『转换为权威数据』，重新走审批与执行。（**建议只在评委明确要求时做**，会多花约 2 分钟） |
| **"为什么左侧菜单只有这几个模块？"** | "本次演示聚焦目录编目、数据归集、数据治理的操作主线，因此菜单只呈现相关路径。完整系统模块见技术要求全书。" |
| **"演示超时怎么办？"** | 最省的降级路径：**跳过步骤 3 的归集工单审核**（直接进归集系统说明"工单已流转"），以及**跳过问题清单的筛选与分页**，直接讲五项数字与视窗。可压到 7 分钟。 |

## 五、故障处置

| 现象 | 处置 |
|---|---|
| 页面白屏 | 确认用的是 **Chrome**；按 `F5` 刷新重试。文件可离线运行，无需网络。 |
| 走到一半状态乱了 | 进 **【治理成效总览】** → **【重置数据】**；或直接关掉重新打开文件。 |
| 上传文件没反应 | 文件选择框需点 **📎 录入待归集数据** 按钮触发；确认选的是 `.csv` 文件。 |
| 弹窗被关掉找不到了 | 大部分操作在页面上留了对应按钮（如【前往…】），也可直接从左侧菜单进入对应模块。 |
| 右下角一直有个深色面板 | 按 `Ctrl + D` 关闭调试模式。 |
| 字体显示异常 | 确认系统已装中文字体（Windows 自带微软雅黑即可）。 |
