# 演示脚本

各位评审老师好，接下来我给大家演示政务数据新增编目，通过目录开展数据归集，并对归集数据做数据治理。

## 一、演示新增政务数据目录

1、登录【数据目录管理系统】，进入【数据目录管理】模块，点击【新增目录】，进入新增数据目录页面。

![](data:image/png;base64...)

2、按照页面展示内容，填写目录要素信息，包括基础标识属性（包括数据目录名称、数据提供单位、数据摘要、目录来源）、数据特征属性（包括数据来源系统【注意要先选择一个系统，系统所属分类字段才会带出来】、数据来源系统所属分类、数据所属领域等）、范围界定属性、共享开放属性、事项业务关联属性、发布管理属性、数据项。

![](data:image/png;base64...)

![](data:image/png;base64...)

![](data:image/png;base64...)

![](data:image/png;base64...)

3、上传准备好的数据目录要素信息文件。（数据项的表里至少建3个字段，为后续配置治理规则做准备）

【截图上传功能】

4、数据目录要素信息上传完成后，点击【提交】，进入审核流程。（用超级管理员账号审3次）

![](data:image/png;base64...)

5、进入【我的审批工单】【数据目录审批管理】列表，选择刚创建的数据目录，核对信息，审核工单。

![](data:image/png;base64...)

![](data:image/png;base64...)

6、初审完成后流程进入复审，点击【审核】

![](data:image/png;base64...)

![](data:image/png;base64...)

7、复审完成后流程进入终审，点击【审核】

![](data:image/png;base64...)

![](data:image/png;base64...)

8、终审完成后，在【数据目录管理】列表，查看该条数据目录状态变为“已发布”。

![](data:image/png;base64...)

1、在【数据目录管理】列表，找到该数据目录，点击【归集】按钮，填写归集信息，包括对接方式、表英文名、数据用途等信息。

![](data:image/png;base64...)

![](data:image/png;base64...)3、进入【数据归集审批管理】列表，找到该审批工单，点击【审核】，即可审批该工单信息。

![](data:image/png;base64...)

![](data:image/png;base64...)

4、审核通过后，工单自动流转至数据归集子系统。

![](data:image/png;base64...)

## 五、演示数据治理规则配置

在系统中为待治理数据配置治理规则。

1、登录【一数一源一标准治理系统】，进入【数据治理配置中心】【数据治理规则配置】列表，选择该数据目录名称，点击【配置】，进入规则配置详情页。

![](data:image/png;base64...)2、配置一数一标准规则，

选择数据字段XXX01，选择【一数一标准】模式，关联XXX01治理规则；

选择数据字段XXX02，选择【一数一标准】模式，关联XXX02治理规则；

选择数据字段XXX03，选择【一数一标准】模式，关联XXX03治理规则；

为当前待治理数据配置不少于3项一数一标准校验规则。

![](data:image/png;base64...)

![](data:image/png;base64...)![](data:image/png;base64...)![](data:image/png;base64...)![](data:image/png;base64...)3、点击【下一步】，开始配置一数一源规则。

是否需进行关联校验：是。

将待治理数据关联到演示数据集中权威数据源进行比对，设置主关联字段与验证字段；异常数据处理策略至少包括“保留原值”和“转换为权威数据”2种。本次演示选择“保留原值”。

关联权威数据源：选择数据源名称XXXXX（需提前内置权威数据源）

设置主关联字段：字段名称XXX01

设置验证字段：字段名称XXX02

异常数据处理策略：保留原值。

![](data:image/png;base64...)![](data:image/png;base64...)![](data:image/png;base64...)

4、完成上述配置，点击【提交】，即可完成数据治理规则配置。在【审批管理】列表对治理规则进行审核，通过审核后系统创建治理任务。

## 六、演示数据治理

1、进入【一数一源一标准治理系统】的【治理任务管理】列表，找到XXXX治理任务，验证系统创建时间为规则审核通过时间，即当前时间。

![](data:image/png;base64...)

2、点击【配置】，填写治理任务调度详情。

![](data:image/png;base64...)

3、、点击【提交】，治理任务状态变为【已上线】，同时系统执行该治理任务。

![](data:image/png;base64...)

4、在【监控运维中心】【任务实例运维管理】列表，查看该治理任务执行情况。

![](data:image/png;base64...)

5、任务实例状态变为【已结束】，说明治理任务执行完成，数据从归集仓治理到清洗仓。

6、进入【统一问题工单】【数据清洗结果明细】列表，在【问题清单】中可看到，归集数据总量是XX条，经过去重规则治理，得到去重后数据量XX条，经过治理规则后得到清洗数据总量XX条，其中优质数据XX条，问题数据XX条。

查看【问题数据明细】，有过滤、转换、保留原值、去重等问题类型，可以查看问题清单并导出，可以确认被保留原值的异常数据明细样本。
