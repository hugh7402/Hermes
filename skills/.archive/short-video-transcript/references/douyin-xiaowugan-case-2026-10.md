# 实战：抖音小物竿测评 → 18 款鱼竿价格表（2026-10-01）

## 任务

用户发来抖音分享链接（作者「大梨花吖」，标题《最全品牌20+款小物竿！录了整整两天！优缺点无保留分享！》），
要求：**把视频里鱼竿的价格查出来，列成表格，在京东上查**。

→ 视频里的信息（品牌/型号/优缺点）必须从**画面烧录的字幕**提取，因为分享页拿不到文案。

## 四、🚨 OCR 错字纠正表（下游用型号名时必须先校正）

| OCR 输出 | 真实值 | 怎么发现的 |
|---|---|---|
| 北禾**矾** | 北禾**婵** | 去淘宝搜关键词搜不到 → 搜品牌名找到真型号 |
| 柳**荫** | 柳**莺** | 同上（YGC 柳莺 28 调） |
| **杯子** | **杆子** | 上下文不通，且全片反复出现 |
| 鹅鹕钓 | 鹈鹕钓 | 搜不到 → 换成品牌名搜到 PWS 天展竿 |
| 度度鸟 | 渡渡鸟（DODOWORKS） | 搜品牌时发现英文名 |

**教训**：OCR 出来的型号**不能直接当搜索词**。拿到候选后先去商品站搜一下，
搜不到立刻换相近字重试，**不要报一个不存在的型号给用户**。

## 五、下游衔接：从口播稿到价格表

口播稿 → 提取出 **18 款品牌/型号 + 作者对各款的优缺点原话** → 去京东/淘宝查价。

- 价部分走 `cn-shopping-links` skill（京东价格掩码规则、smzdm 真实价渠道、交付表格格式）
- 交付时把**作者原话的优缺点**也列进表（用户没要求但确实想要——它直接支撑"买哪根"的决策）
- 用户后续追加了「按价格排序」→ 排序时要**声明排序依据**（跨平台取最低可得实价），
  因为有一部分款拿不到确定价，不声明会被追问

## 六、复用清单

本案例产生的脚本（临时目录 `/opt/data/.tmp_tests/`，逻辑见 SKILL.md）：

| 脚本 | 作用 |
|---|---|
| `dy_get.sh` | 调第三方解析 API 拿视频直链/标题/时长 |
| `dy_fetch.sh` | 下载 mp4 + 抽音频 + 环境探测 |
| `dy_probe2.sh` | 抽 10 帧试跑 OCR（**先看看有没有屏幕文字**） |
| `dy_ocr.py` | 全量逐帧 OCR（并发 6 + 断点续传） |
| `dy_build2.py` | 时间轴重建 + 去重 |

> **先跑 `dy_probe2.sh` 这种 10 帧试跑**：花 10 秒就能确认"画面到底有没有字幕"，
> 比直接跑 553 帧安全得多。
