# 锁车 / 车机音效：找源、下载、压格式、装车

## When to Use

用户要给车换锁车声/迎宾音/换挡音，问车上到底能自定义哪几种音效，
或要“贾维斯/钢铁侠那种”音效时。不适用于音箱/手机铃声等非车机场景。

## 车机硬约束（比亚迪实测，先问清楚再下）

- **格式 WAV**，单文件 **< 1.5MB**（用户海狮08 EV 实测限制；先问用户他车机的限制，别假设）。
- 交付统一 **44.1kHz / 16bit / 立体声 pcm_s16le**：`ffmpeg -ar 44100 -ac 2 -c:a pcm_s16le`。
- **时长 1–3 秒最佳**：超过 3 秒每天听会烦，部分车机会截断。超长且超体积的，另出裁剪版
  （`-t 3.5 -af afade=t=out:st=3.2:d=0.3`），原件同时保留。

## 两个可用音源（2026-10 实测）

### ① teslalocksound.com —— 原版 WAV 直链，**首选**

有公开只读 API（`/agents.md` 与 robots 都明示允许，60 次/分钟，无需 key）：

| 用途 | 调用 |
|---|---|
| 搜索 / 排行榜 | `GET /api/v1/sounds?q=<词>&per_page=100&sort=downloads&order=desc` |
| 单条详情 | `GET /api/v1/sounds/{uuid}` |
| 取 WAV | 列表项里的 `file_url`（Supabase 公开存储，curl 直下，无需 Referer） |
| 分类 | `GET /api/v1/categories`（15 类：Sci-Fi/Gaming/Retro Tech/Vehicles…） |

⚠️ **UUID 必须用搜索结果里的完整 `id`**，拿前缀去查详情会返回没有 `file_url` 的对象
（本次因此白失败 6 条）。

**搜索要换近义词多查几轮再按 `id` 去重**：`jarvis` / `iron man` / `stark` 三个词命中的集合互相交叉，
且每条结果都带 `title / category / duration / downloads / file_url`，直接合并去重就能排出候选表；
只查一个词会漏掉同主题的另一批。

### ② sound.jichun29.cn（鹏友锁车音效分享平台）—— 中文圈、厂牌全，但只能拿转码件

- 页面 JS 渲染，搜索框 `#searchInput`；条目链接 `/pages/sound.php?id=N`。
- **下载按钮后面挂滑动验证码**（`download.js`）→ **不要绕过验证码**。
- 可自动拿到的是试听流：`GET /api/stream.php?id=N`（带 `Referer: .../sound.php?id=N`）
  → **64kbps MP3**，再 `ffmpeg` 转 WAV。交付时必须标注"转码件、非原件"。
- 厂牌分类：特斯拉 / 小米汽车 / 小鹏 / 极氪 / 领克 / 问界 / 理想 / 蔚来 / 阿维塔 / 九号。

其它：爱给网 aigei.com 有贾维斯 `see you sir` 等（WAV/SQ），但**需登录**才能下。

## 工作流（用户偏好：先列表、确认后再下）

1. 先出**候选列表**：名称 / 时长 / 大小 / 下载量 / 来源链接，并给 2–4 个"我首推"。
2. 用户圈定（或说"全都要"）后再下载；每文件 `ffprobe` 验 `codec_name=pcm_s16le` + 体积 + 时长。
3. 超 1.5MB 的要么剔除要么出裁剪版；**原件与裁剪版都留**，别替用户做取舍。
4. 产出：`A-原版WAV/`、`A-原版WAV/超限已裁剪/`、`B-转码WAV/` + `清单.md`（含每组来源与转码说明）+ zip。
5. 备注版权：漫威等音源仅限个人车机自用。

## 装车路径（比亚迪）

`设置 → 车辆控制 → 锁车音效`（2026 OTA 后部分车型可直传自定义音频）→ 没有该菜单则 U 盘 FAT32
根目录放 `LockChime.wav` → 车机「文件管理」导入 → `车辆设置 → 声音设置 → 锁车提示音` 选择。
兜底：迪加（1.3.8）+ 无线 ADB，音频放 `vandiplus/audio`；属动系统配置，OTA 可能覆盖、质保可能争议。

## 车上到底能改几种（回答这类问题时别混为一谈）

1. **车机官方可直接改**：锁车提示音、车辆提示音源（标准/品牌/舒适 三档音色）、转向灯声、
   低速行人提示音（法规要求，不建议关）、语音唤醒词/迎宾语。真正"换音效"的只有锁车提示音这一项。
2. **需迪加 + 无线 ADB**：车外锁车音效、换挡音效。
3. **改不了**：安全带未系提示、倒车雷达报警、ADAS 预警音（安全强制）。
4. 具体开几项**取决于车机版本**（DiLink 100 vs 150 不同，同款低配可能没有自定义锁车音效）。
