# 周报生成器 · Weekly Report Generator

纯 Prompt-based Skill，无需代码依赖，通过 AI 对话直接生成结构化报告。

## 使用方式

直接告诉我你的职业角色和工作内容，我会自动匹配模板生成结构化周报。

### 最简模式

```
我是前端工程师，本周完成了登录页面重构，修复了 3 个 Bug，下周要做首页性能优化，帮我生成周报。
```

### 标准模式（推荐）

```
帮我生成周报：
- 职业角色：后端工程师
- 汇报对象：技术总监
- 本周完成：用户中心微服务拆分（80%）、接口性能优化（800ms→200ms）、修复P1 Bug 2个
- 进行中：订单服务重构
- 问题：数据库连接池配置导致压测失败，已解决
- 下周计划：订单服务重构完成、支付模块开发
```
