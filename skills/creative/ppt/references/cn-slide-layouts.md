# 中文汇报单页版式库

目标画幅 **1280×720 px（= 13.333×7.5 英寸，16:9）**。以下坐标均在此画幅、直接写进 SVG 的 `x`/`y`。

## 一、栅格基准

| 项 | 值 |
|---|---|
| 页边距 | 左右 56；顶部标题基线 44（白底标题区）或 54～55（深色标题带）；页脚线 686，页脚字基线 700～706 |
| 内容区（版式 E 首选用这个） | x 56 → 1240（宽 1184） |
| 内容区（版式 A 双段用） | 左锚柱宽 296（含 4px 品牌色边条）；右侧 x 336 → 1240（宽 904） |
| 5 列分栏 | 列宽 ≈ 163–218，列间距 20–24；分隔发丝线 `#FBD5D8` |
| 小节标题 | 4×15px 红色小方块 + 13px 粗体 + 7.5px 英文小标（字间距 1.3）+ 发丝线延到 1240 |
| 字号阶梯 | 页标题 21–22 / 小节名 13 / 列名 13–13.5 / 行名 12–12.5 / 正文 9.2–9.5 / 页脚 8 |

选择版式前先确定用哪套内容区：版式 E 是全宽 1184，版式 A/B 是右侧 904。**改版式时要重算列宽，不能延用上一版的坐标。** 不论哪套，右侧区块的右端、发丝线端点、页脚线端点**必须全部对齐到 1240**，参差最容易被看出「不整」。

## 二、五种版式与实测结论

### 版式 E：国企稳重版 · 白底黑字标题 ＋ 浅红分区（**首选，国企/政务都用这个**）

最终定稿的版式。无深色竖栏，分量来自标题层级与浅色分区块的节奏。

- **标题区（白底，绝不上色块）**：黑体 22px 粗体 `#1A1A1A`，x=56、基线 y=44；右上角 logo 签位 (1116, 18, 132×34)；通栏细红线 `#E60012` 1.6px，y=76，x 56→1240
- **职责定位带**：通栏极浅红 `#FDF3F4`，y 88→168（高 80）。左侧实心红标签 (56, 104, 78×26)、白字 9.5px 居中；两行说明 x=150，基线 117 / 139，10.5px `#4A4A4A`
- **主要职责**：小节标题基线 y≈196；5 列浅红卡 y 210→326（高 116、rx 3、`#FDF3F4`），每卡顶部一条 3px `#E60012`；卡内编号 11.5px 红 → 列名 13px 粗体 → 24×2 红短横 → 说明 9.2px 三行 dy16.5
- **主要工作内容**：小节标题基线 y≈362；5 行条 y 378 起、高 46、间距 8；左端 3.5px 红条；大数字 15px 红、行名 12px 粗体（基线 y+19）、说明 9.2px（基线 y+37）；**左右两栏分隔线统一 x=866，右栏统一 x=884**
- **协同支撑**：通栏 `#FDF3F4` y 654、高 34，左端 3.5px 红条；标签红色粗体，其余灰字
- **页脚**：字基线 y≈706，页码右对齐 1240

两段版式刻意区分（上段横列卡、下段横条行），不要两段都做成同一套等宽卡片。

### 版式 A：深色左锚柱 + 右双段（**国企/政务场景否决**）

左侧 296px 石墨黑灰渐变 `#191D22 → #232930 → #2C333C`，最左 4px `#E60012` 边条；右区白底。

- 左栏：顶部英文小标（8px，白 .56）→ 「职责定位」（11px 粗体白）+ 2px 红短横 → 定位正文（9.8px，白 .87，行距 19）→ 「协同支撑」（11px 粗体）+ 4 条带 `#FF5A63` 圆点条目（8.6px，白 .90）
- 左栏两块内容**上下锚定**：上块 40→213，下块 470→626；中间 213→470 的空隙用 2–3 层同心圆（r 102/70/44，白 .06/.05/.04，圆心约 y=342）填层次
- 右区上段：主要职责 5 列（编号 11.5px + 列名 13px 粗体 + 24×2 红短横 + 说明 9.2px 三行 dy16.5）；分隔线 y122→246
- 右区下段：重点工作 5 行（行高 60、行距 70、浅底 `#FDF3F4` 圆角 4、左端 3.5px 红条；大数字 17px 红在最左，行名 12.5px 粗体，下方左栏说明在 x406；分隔线统一 x866，右栏指标统一 x884）

**双段结构本身可用，但深色竖栏在国企/政务汇报中被否决**——「有点互联网风格，我们是国企，要以稳重传统为主」。要保留左栏承载定位与协同的叙事，就换版式 E 的白底形态。

### 版式 B：全白扁平表格式

无左栏，靠细红竖条、编号、发丝线建结构。职责 5 列横排，重点工作 5 行「名称｜动作｜指标」三栏。

**备选，不要默认用**。结构干净但会被评价「太素雅」。用好它的前提是配套加了收口线（五列下方一条通栏发丝线拉齐下沿）与页脚呼吸区。

### 版式 C：深红左锚柱（**否决**）

结构与 A 同，但左栏是 `#9B000D → #E60012` 红渐变。视觉冲击最强，但被明确要求拆掉。**不要再用。**

### 版式 D：十等权卡片网格（**否决**）

5 列职责 + 5 列内容，全部同尺寸浅底卡片。十个等权块相互稀释，没有视觉重心，看起来像表单不像设计。

## 三、一页容量

| 项 | 经验值 |
|---|---|
| 正文字数上限 | ~800 字已偏满，超过就建议拆页 |
| 正文最小字号 | 9.2px @1280 画幅（投影 1080p 约等效 13.8px），再小投影读不动 |
| 行内两栏 | 左栏 ≤ 50 字、右栏 ≤ 48 字（9.2px 下）才不会碰分隔线 |
| 卡片内文字 | 框高留 13pt 以上余量，按「字宽≈字号」算行数 |

## 四、改稿迭代纪律

1. 先渲图再看，不要盲改坐标（`cairosvg` → `vision_analyze`）
2. vision 报的问题里，**文字/数字一律回源核实**，核实不上就不改；只采纳「结构/对齐/间距/留白」类意见
3. 每轮只改一类问题（拥挤 → 对齐 → 重心），一轮改太多会不知道是哪处没修好
4. 改完必须重渲再确认，不要接着叠改
5. 要用户挑版本时，拿**同一结构的不同色块强度**去比（如全白扁平 / 浅红分区 / 局部实心红标签），不要拿已否决的深色竖栏或深红铺底当候选——那只会多绕一轮

## 五、内容顺序（汇报类单页）

定位（谁、干什么）→ 职责（分工）→ 重点工作（做什么 + 指标）→ 协同支撑（跨部门横向）。
每段标题用「中文名 + 英文小标」两行式，比单中文标题更有版式感，且英文小标不承载信息、改稿时不用同步。
