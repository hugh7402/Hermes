# 抖音小物竿视频提取实录（2026-10-01）

**任务**：用户发来抖音链接（作者「大梨花吖」，《最全品牌20+款小物竿》），
要求「把视频中鱼竿的价格查出来，列成表格，在京东上查」。

## 2. 抽帧 + OCR

- `ffmpeg -i rod.mp4 -vf fps=1 -q:v 2 all/f%04d.jpg` → **553 帧**（视频 552.8s）
- 画面 576×768（竖屏），hevc + aac

### prompt 对照实验（3 帧：p1/p4/p8）

| prompt | LOC 噪声 | 输出样例 |
|---|---|---|
| `请提取图片中所有文字，保持原文段落结构。只输出文字，不要加解释。` | 0 | ⚠️ 但 553 帧全量跑时**全部返回坐标** `498,878,55,305,90` |
| `OCR this image. Output only the text you see, line by line. If no text, output NONE.` | — | 坐标 |
| **`Text Recognition:`** | 0 | ✅ `年终小物钓 / 鱼竿合集来啦 / 今年我踩过的坑` |

**注意**：同一条自由文本 prompt 在 3 帧试跑时**偶尔出文字**，全量跑才暴露坐标问题——
所以「试 3 帧」不够，要**看输出是不是中文字**（出现 `数字,数字,数字…` 立刻停）。

### 实测指标
- 553 帧 / 并发 6 / **199 秒** / **250,554 token**（≈453/帧）/ **≈¥0.075**
- 去重后 **466 段有效字幕**

## 3. 引擎准确率对比（同帧）

| 帧 | 百炼 qwen-vl-ocr | 本地 rapidocr_onnxruntime |
|---|---|---|
| t=300s | 既有那种**直男**的粗旷感 | 既有那种**查男**的粗旷感 |
| t=480s | 一整套下来才100多 | `180.` \| `主线始` \| `S` \| `壹桶` \| 整套下来才100多 |

本任务产出的是**型号清单**，关键字错一个就废 → 必须用百炼。

## 4. OCR 错字纠正表（同音/形近字，必须二次核实）

| 视频口播（OCR） | 实际型号 | 反查方式 |
|---|---|---|
| 北禾**禅** | 北禾**蝉** | 淘宝搜到「北禾蝉溪流竿 35.5cm」「北禾蝉Pro9系」 |
| 柳**荫**（二八调） | YGC **柳莺** 28调 | smzdm 价格库里有「YGC 柳莺短节溪流竿 2.2-3.6m 28调」 |
| 度度鸟 | **渡渡鸟** DODOWORKS | 搜「渡渡鸟双定位天展竿」 |
| 鹅鹕钓 | **鹈鹕钓** PWS | 搜「鹈鹕钓 PWS 天展」 |
| 「杯子」 | 「杆子」 | 上下文判（OCR 把杆认成杯） |

交付时注明「视频口播作 X，实际型号为 Y」。
