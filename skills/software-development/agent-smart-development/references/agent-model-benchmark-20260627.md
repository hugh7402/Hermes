## 核心结论

### 1. 非推理模型碾压推理模型
- deepseek-v4-flash 2.0s vs 推理模型平均 18.5s — **9x 速度优势**
- 推理模型在 tool-call 循环中每次都要"思考"，Agent 做 N 步就需要 N × 延迟
- glm-5.2 在"模糊意图"测试中推理 token 耗尽了 max_tokens，输出被截断，仅得 1/10

### 2. deepseek-v4-flash 全面胜出
- 最快：2.0s 平均延迟
- 最准：所有任务满分
- 最便宜：¥0.0019/4call
- 0 推理消耗：Agent 循环中不用等待"思考"

### 3. qwen-plus 是最佳备用
- 4.4s 延迟对大多数场景足够用
- ¥0.0024 性价比高
- 百炼平台稳定可靠

### 4. 智谱 GLM 系列不适合 Agent
- glm-5.1 工具调用格式混乱（markdown 包裹 JSON 导致解析失败）
- 两者都是重推理模型，延迟高且容易截断

### 5. qwen3.7-max 分数高但不可用
- 均分 9.2 但 26.1s 延迟，Agent 循环中一步等半分钟
- 成本 ¥0.1166，是 flash 的 61 倍
