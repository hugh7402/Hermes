# 京东/淘宝查价实录（2026-10-01 小物竿 18 款比价）

**任务**：用户发来一条抖音测评视频，要求把视频里 20+ 款小物竿的**价格查出来、列成表格、在京东上查**。

---

## 一、京东的「价格可见性」规则（核心结论）

**京东对未登录访客隐藏价格。** 这是整套流程的出发点。

| 页面形态 | 价格可见性 |
|---|---|
| `https://item.jd.com/<纯数字 sku>.html`（老式） | ❌ `¥ 4??` + 「登录查看价格」 |
| `https://item.m.jd.com/product/<纯数字 sku>.html`（老式移动端） | ❌ 同上，`¥ _4??_` |
| **`https://item.jd.com/product/<hashId>.html`（新式，hash 形如 `0ffUdiznnb85c4DrixK0QA`）** | ✅ **完整价格**（`¥ 129.00`），搜索摘要里就带 |

**掩码首位数是真的**，可换算区间：

| 掩码 | 区间 | 例 |
|---|---|---|
| `¥3?` | 30–39 | 小树家替换握把 |
| `¥2?` | 20–29 | 子非鱼线组 |
| `¥1??` | 100–199 | 百卡龙小物竿套装 |
| `¥3??` | 300–399 | 鲸至 Relax |
| `¥4??` | 400–499 | CAMPFISH 无限换把 1.8m |
| `¥5??` | 500–599 | 响猫 4E 小物竿 3.6m 套装 |
| `¥9??` | 900–999 | 渡渡鸟双定位天展竿 |

**位数的含义**：`¥3?` 是两位数（¥3x），`¥3??` 是三位数（¥3xx）。别搞混。

## 二、被拦死的通道（别再浪费轮次）

| 通道 | 症状 |
|---|---|
| `https://search.jd.com/Search?keyword=...` | 302 → `https://cfe.m.jd.com/privatedomain/risk_handler/03101900/?evApi=color-mesh_A_SC_pc_search_java_Search&...`（跟随后 HTTP 200 但只有 2704B 风控壳页）|
| `https://so.m.jd.com/ware/search.action?...` | 同上 302 到风控页 |
| `https://api.m.jd.com/client.action?...` | `403 {"code":"1","echo":"cross-origin request from '' is not allowed"}`；补 Origin/Referer 后变 `{"code":"1","echo":"no access"}` |
| `https://item.m.jd.com/ware/detail.json?wareId=...` | `404 {"status":404,"error":"Not Found","path":"/ware/detail.json"}` |
| **`https://p.3.cn/prices/mgets?skuIds=J_<sku>`** | **本机 DNS 被 sinkhole**：`getent hosts p.3.cn` 返回 `172.28.59.58 / 10.199.200.133 / 172.26.101.78`（**内网地址**）→ 直连 `timeout`、走代理 `HTTP 000`。**这是环境级 DNS 拦截，不是 API 失效**——换机器可能可用，但本机放弃 |
| 走代理访问京东 | 同样返回 2704B 风控页（代理出口 IP 也一样被识别）|
| `www.gwdang.com`（购物党） | 返回 3227B 挑战页 |
| `search.smzdm.com` | HTTP **202** + `probe.js` 挑战页（但 `wiki.smzdm.com` / `m.smzdm.com/p/<id>/` 的文章页可通过 web_search 摘要拿到）|

### 京东 SEO 聚合页能直连，但没有价格

以下均 **HTTP 200、500KB+ 真内容**，可直连（`curl --noproxy '*'`）：

- `https://www.jd.com/jiage/<hash>.html`（「XX价格报价行情」）
- `https://www.jd.com/hprm/<hash>.html`
- `https://www.jd.com/hotitem/<hash>.html`
- `https://www.jd.com/brand/<hash>.html`
- `https://www.jd.com/chanpin/<id>.html`

**但价格是 JS 动态加载的**：HTML 里只有空壳
`<div class="price p-price" data-skuId="100246488298"></div>`，值走 `p.3.cn`（本机不可达）。
页面里**能拿到的是商品标题 + skuId**（`<a href="https://item.jd.com/<sku>.html" class="img-href" title="完整商品名">`）——
这批标题是后续用 smzdm/淘宝查价的**搜索词来源**，价值很高。

## 三、可用通道（按优先级）

### ⭐ 1. 京东新式 hash 商品页

`item.jd.com/product/<hashId>.html`，搜索摘要里直接带完整价。
搜法：`web_search "<完整商品标题> 京东 价格"`。
实测拿到：北禾御山三代 3.6m `¥129.00`（三色同价，2.7m 版 `¥99.00`）、YGC 柳莺pro 3.6m `¥409.00`。

### ⭐ 2. 什么值得买（smzdm）—— 拿到京东真实价的主力

| 页面形态 | 内容 |
|---|---|
| `wiki.m.smzdm.com/p/<id>/` 或 `wiki.smzdm.com/p/<id>/` | 「价格趋势」板块：**常卖价 / 历史最低 / 历史低价 / 30天低价 / 双十一 / 大促价** + 具体日期 + 规格参数 |
| `m.smzdm.com/p/<id>/`（爆料） | **带店铺名的完整下单链**：`京东 响猫京东自营旗舰店 页面价: ¥443.4 → 实付398.4元`，还有「满1元打8折」「立减20%」等活动描述 |

**搜索词**：`<完整商品标题> 报价 价格 评测 怎么样` —— 比喂「品牌+型号」命中率高得多。

实测拿到：
- 响猫 4E 小物竿：页面 443.4 → 实付 **398.4**（京东自营旗舰店，25-10-01）；另一条 498.8 → 399.04（25-04-28）；wiki 常卖 409，历史最低 330.65
- YGC 柳莺短节溪流竿：2.2-3.6m 常卖 339；3.6m 常卖 297；3.3m 常卖 263；3m 常卖 229
- 鹈鹕钓 PWS 270天展竿：页面 498 → 实付 **423.3**（京东 悦野户外卖场店）
- 子非鱼胶囊杆 PRO：常卖 **211**（历史最低 207）

### 3. 淘宝/天猫的商品页（搜索引擎索引版）

`web_search "<完整商品标题> 淘宝"` → 命中 `pcdetail.taobao.com/<base64>.html`、
`mobile-phone.taobao.com/detail/<hex>.html`、`mobile-phone.taobao.com/chanpin/<hash>.html`。
摘要里直接带 **`￥ xxx`** + 店铺名 + 城市 + 付款人数 + **市场价**（可判断折扣幅度）。

实测拿到：KOKOE 小蛙水凤梨 2.1/2.4m **348**（多店同价）；小树家小山 2.0m 套盒 **459**；
渡渡鸟双定位天展竿 **487**；CAMPFISH 无限换把 **215**（含备用竿梢 298）；
北禾蝉 1.8m 暮霞紫 **265.32**；响猫 4E 天展竿 3.6m 套装 289–479。

## 四、京东 vs 淘宝：价差不是单向的

| 商品 | 京东 | 淘宝 | 结论 |
|---|---|---|---|
| 小蛙 KOKOE 水凤梨 | ⚠️500–799 | **348** | 淘宝省 150–450 |
| 渡渡鸟双定位天展竿 | ⚠️900–999 | **487** | 淘宝省 410–510 |
| YGC 柳莺pro 3.6m | ✅409 | 329 | 淘宝省 80 |
| **YGC 柳莺 3m / 3.3m / 3.6m** | ✅**229 / 263 / 297** | 329–369 | **反而京东便宜** |
| 响猫 4E 小物竿 3m | ✅398 | 389–458 | 接近 |

**交付口径**：不要替用户拍板「去淘宝买」。列两个价 + 一句「京东买的是自营售后+发票，淘宝买的是价格」。

## 五、交付格式（用户偏好）

1. **用户要「列成表格」** → markdown 表格，一行一款；**价格列必须标渠道**：
   `京东✅确定价` / `京东⚠️区间` / `淘宝`。掩码区间要明说「这是区间不是实价」
2. **用户要「按价格排序」** → 先声明**排序依据**（跨平台取最低可得实价 / 京东价 / 淘宝价），
   因为有一部分款拿不到确定京东价，不声明依据的排序表会被追问
3. **拿不到价的条目**放最后并注明原因（未上市 / 未上架），不要静默丢掉
4. 排序后附**分档**（如「¥250 以下 / ¥250–400 / ¥400 以上」）+ 一句购买建议，用户直接可用
5. 中间产物写 `.tmp_tests/<topic>_prices.md` 并用 `MEDIA:` 发给用户

## 六、附带发现：未上映新片的「下载站」是木马

同一会话里用户要查一部**未上映**电影的资源，搜索「<片名> 电影 下载」时命中
`m.shouyouuv.com` 之类站点，声称提供「2026真人版<片名>电影流鼻血版本下载」，
实际下载物是 **24MB 的安卓 APK**。
**凡是「未上映新片资源」一律当木马处理，并主动警告用户别点。**
