# 演示防露馅：把原型包装成「真实系统演示」

> 2026-10-11。触发场景：用户说「演示时浏览器显示原型地址目录，专家一眼看出是原型」。
> 同族需求：「让别人（客户/评审）看着像一套真的系统」。

## 一、六处痕迹（界面内的已在 SKILL.md 第十节，这里全是**界面外**的）

| # | 痕迹 | 实测例子 | 为什么扎眼 |
|---|---|---|---|
| 1 | 地址栏 | `file:///Users/shaolei/Documents/Inbox-源文件中转站/四川省数字政府项目/四川省数字政府项目原型/一数一源原型/四川一体化数…` | 路径里**直接写着「原型」**，还泄出项目目录结构 |
| 2 | 页脚版本号 | `…站点地图版本 V2.8` | 迭代版本号＝「这是第 N 版原型」 |
| 3 | 文件名 | `四川一体化数据资源管理系统_V2.8.html` | 同上，且文件名会出现在地址栏/下载记录里 |
| 4 | 书签栏 | `人人影视` `电影天堂` `淘宝` … | 与业务无关的**个人书签摆在专家眼前**，比地址栏更尴尬 |
| 5 | Ctrl+D 调试面板 | 屏号 + CSS 选择器 + 定位串 | 等于自己把「这是可调试的网页」说出来了 |
| 6 | 开发者工具（⌥⌘I） | — | 同上 |

⚠️ 第 2 条**grep 产物文本常常搜不到**：版本号是运行时拼的（`'<span class="ver">版本 ' + VERSION + '</span>'`），
静态搜索只能找到 `'版本 ' + VERSION` 这段拼接代码。**判断「界面上到底显示了什么」必须在运行时读 DOM**
（`document.querySelector('.footer').innerText`），别只 grep 文件。

## 二、三种方案（按推荐度）

### 方案 A：Chrome 应用模式（首选，5 分钟，零基础设施）

```bash
# 关键在两个参数：--app 去外壳，--user-data-dir 换干净配置
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --app="$URL" \
  --user-data-dir="$HOME/.drs-demo-chrome" \
  --no-first-run --no-default-browser-check
```

- `--app=` → **无地址栏、无标签页、无书签栏**，窗口标题＝页面 `<title>`（写上系统全称即可）
- `--user-data-dir=` → **独立配置**，不带出用户日常 Chrome 的书签/历史/扩展（第 4 条痕迹顺手解决）
- 全屏无边框：`--kiosk`（⌘Q 退出）
- ⚠️ Mac 上 **F11 是「显示桌面」**，别教用户按 F11；全屏用 ⌃⌘F

### 方案 B：本机服务 + 伪域名（更像政务系统）

```bash
cd ~/Demo && python3 -m http.server 8080 --bind 127.0.0.1
sudo vi /etc/hosts        # 追加：127.0.0.1  drs.sc.gov.cn
```

- 地址栏变成 `http://drs.sc.gov.cn:8080/`，观感最好
- ⚠️ **http 会显示「不安全」徽标**，比 `file://` 还扎眼 → **只有配合方案 A（地址栏不可见）才划算**
- 用 `http://localhost:8080/` 时 Chrome 不给「不安全」标签，但地址栏就写着 localhost
- **本机服务是既方便又安全的选择**：`--bind 127.0.0.1` 只监听本机；**投标保密件一律不上公网**

### 方案 C：内网部署（最像「系统已上线」）

单文件 HTML 丢内网 nginx / 一台闲置机器，用 IP 访问。需要场地有机器；**同样禁止放公网**。

### 方案 D：只清路径与文件名（零成本，治标）

挪到中性目录（如 `~/Documents/Demo/`）＋ 改名为不含版本号的名字。不解决 `file://` 本身。
（用户的实际路径里同时含「四川省数字政府项目原型」与「一数一源原型」两层，必须挪。）

## 三、演示版产物的派生与验收

演示版是**从交付版派生的第二个产物**，只做「去痕迹」，**功能一字不动**（不要重新构建，避免引入差异）：

| 手术 | 锚点（本项目源码位置） |
|---|---|
| 页脚版本号 | `src/app.js`：`'<span class="ver">版本 ' + VERSION + '</span>' +` → `'' +` |
| 禁用调试开关 | `keydown` 分支里 `e.preventDefault(); toggleDebug(); return;` → `return;` |
| 中性化版本常量 | `var VERSION = 'V2.8';` → `var VERSION = 'V1.0';` |

**验收用例（必须带开发版对照，否则等于没验）**：

```python
# 对照：开发版页脚必须仍带版本号
chk('对照', '版本' in dev_footer, ...)
# 演示版：页脚无版本号，但其余列明项完好（别把整个页脚删掉）
chk('①', '版本' not in demo_footer and '站点地图' in demo_footer and '备案编号' in demo_footer)
# Ctrl+D 无效
pg.keyboard.press('Control+d')
chk('②', pg.evaluate("getComputedStyle(document.getElementById('dbgbox')).display") == 'none')
# 标签页标题＝系统名（不要出现文件名）
chk('③', pg.title() == '四川省一体化数据资源管理系统')
# 功能未变：切屏 + 核心屏渲染 + 无 JS 报错
```

⚠️ 页脚元素是 `.footer`（不是 `.foot`）—— 选择器写错会得到空串，**两个对照都失败、看起来像「版本号本来就没有」**，
本轮就在这里误判过一次（空串比对恒真/恒假的陷阱，同 SKILL.md 九之十五 ④ 的「假通过」）。

## 四、交付物形状（用户 2026-10-11 认可）

```
演示启动包_V<x>/
  四川省一体化数据资源管理系统.html    演示版（页脚无版本号、Ctrl+D 禁用、APP.VERSION 中性）
  启动演示.command                     Mac 双击：本机服务 + Chrome 应用模式 + 独立配置
  启动演示.sh                          同上（.command 被 Gatekeeper 拦时用 bash 跑）
  演示前检查清单.md                    见下
  演示版效果_首页.png                  让用户不拆包就能看到效果
演示启动包_V<x>.zip                   以上打包（HTML 压得动，680KB → 约 150KB）
```

**包里不要放开发版留档** —— 演示文件夹要干净；开发版留在项目交付目录即可。

### 演示前检查清单要点

1. **文件夹放在路径不含「原型」的位置**；双击 `.command`；Gatekeeper 提示时**右键→打开→打开**，
   或 `xattr -cr <文件夹>`（只解除该文件夹的隔离）；双击无反应则终端 `bash 启动演示.command`。
2. **结束动作要写清**：先关系统窗口，再回终端窗口按 **⌃C**（服务靠 `trap` 停掉）。
3. 浏览器：用脚本自带的独立配置；自己开窗口务必 **⌘⇧B 隐藏书签栏**。
4. 系统：输入法切英文、关通知（专注模式、退出微信/钉钉）、缩放 **⌘0**、**别进全屏**（切换动画打断讲解）。
5. 别做：**Ctrl+D**、**⌥⌘I**、在地址栏附近停留输入。
6. 可选加分：`--kiosk`、伪域名；**若现场有内网机器，部署到内网 IP 效果最好**。
7. 故障对照表：双击没反应／窗口带地址栏（说明没找到 Chrome）／白屏（脚本会自动换端口，或双击 HTML 用 `file://`）／
   服务中途停（终端窗口被关，重开脚本 + 刷新页面）。

## 五、跨平台脚本的诚实交付

本轮启动脚本是 **macOS 专用**（`.command`、`open`、`/Applications/…`），而 agent 跑在 Linux —— **无法真跑**。做法：

1. `bash -n 启动演示.command` 过语法（能做，但**只证明语法**）；
2. 把平台无关的部分**真实测**：演示产物本身用真 Chrome 跑完整用例（本轮 11 项全过）；
3. 脚本里写**回退链**：无 Chrome → `open "$URL"`；无 python3 → `file://`；端口占用 → 自动 +1；
4. 交付说明里**明说「这条没在 macOS 上真跑过」**，请用户把终端输出回传 —— 
   **不要把「语法通过」说成「已验证可用」**。
