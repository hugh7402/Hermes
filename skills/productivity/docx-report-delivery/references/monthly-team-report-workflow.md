## 生成方法：模板段落深拷贝

复制上一期 docx → `Document()` 打开 → `copy.deepcopy` 各类型段落元素（title / info1 / info2 / H2 / 编号正文）→ 清空 body 内 `w:p`（**保留 `sectPr`**）→ 按内容顺序 `body.insert` 回 → save。

骨架：

```python
import shutil, copy, os
from docx import Document
from docx.oxml.ns import qn

shutil.copy(SRC, DST)
d = Document(DST)
p = d.paragraphs
title_elm, info1_elm, info2_elm = (copy.deepcopy(p[i]._element) for i in (0, 1, 2))
h2_elm, num_elm = copy.deepcopy(p[3]._element), copy.deepcopy(p[4]._element)

def set_text(elm, text):          # 只改第一个 run，字体/字号/缩进全部继承
    runs = elm.findall(qn('w:r'))
    for r in runs[1:]:
        elm.remove(r)
    t = runs[0].find(qn('w:t')) if runs else None
    if t is None:
        t = runs[0].makeelement(qn('w:t'), {}); runs[0].append(t)
    t.text = text

body = d.element.body
sectPr = body.find(qn('w:sectPr'))          # 必须保留
for q in list(body.findall(qn('w:p'))):
    body.remove(q)
for kind, text in content:                   # content = [('title', …), ('h', …), ('num', …)]
    elm = copy.deepcopy({'title': title_elm, 'info1': info1_elm, 'info2': info2_elm,
                         'h': h2_elm}.get(kind, num_elm))
    set_text(elm, text)
    body.insert(list(body).index(sectPr), elm)
d.save(DST)
```

- 段落索引与 `docx_read.py --structure` 的 outline 对应（0=title, 1=info1, 2=info2, 3=H2, 4=正文…）
- 复用脚本：`/opt/data/scripts/gen_report_docx.py`（2026-08-22 生成 7-8 月版时写的，策略=复制 6 月版当模板）

## 模板二：团队月度会汇报材料（2026-10 起启用）

⚠️ 这是**另一套**模板，跟上面的《团队月度重点项目汇报材料》不是同一个东西，别混用。
用户发来的模板文件名形如 `XXXX团队<N>月月度会汇报材料.docx`。

六段固定结构：

1. 收入利润目标差异及完成计划
2. 应收账款完成情况
3. 五融推进情况
4. 重点产品、重点商机及规模以上收入项目进展（重点产品 1-2 个；商机/项目；规模以上收入项目不超过 5 个）
5. 年底集成收入攻坚项目进展
6. 其他重点工作事项

### 格式基线（模板自带，就地填充时继承，勿重设）

| 元素 | 规格 |
|---|---|
| 标题 | 仿宋 15pt 加粗居中（`Normal (Web)` 样式） |
| 团队名称/汇报人行、汇报时间行 | 仿宋 12pt 加粗，段前段后 6pt，行距 1.2 |
| 六个章节标题 | 仿宋 12pt 加粗，段前 15pt、段后 6pt、行距 1.2 |
| 正文 | 仿宋 12pt；模板自身无首行缩进，填充时给 24pt 更接近公文体 |
| 页面 | A4；边距模板未显式设置（`section.*_margin` 为 `None`，打印前要判空） |

### 章节落位（团队口径）

- **「年底集成收入攻坚项目进展」** = 陕西智慧民政一体化平台二期 + 四川省数字政府（一体化数据资源管理系统）
  **两个项目都写在这一节**，各按「项目定位／总体进度／已落地成果／主要卡点／下一步攻坚举措」分段。
- **「重点产品」固定写 2 个**：民政大脑与业务看板产品化、政务数据目录管理产品（含 9 类编目模板的可复制性）。
- 收入利润、应收账款、五融三节是财务口径，团队侧拿不到数 → 写【待补：具体缺什么口径】，
  交付时编号列出要补的项；**不要拿上期数字顶替**。
- 民政进展的硬数据只能来自**最新一期双周任务清单**；没有就把「任务总数/完成数/进度/延期数」列成一项待补。
- 四川省数字政府项目在月报里只写到「不得超采购限价、实质性条款与▲条款不得负偏离」层级，
  **不写具体限价数字**；已完成工作可写：450 条需求全量解析、21 项▲+4 处★锁定、原型定稿、述标脚本、审核清单四表。

模板自带的填写提示语（如「1-2 个重点产品，」「重点商机 / 项目，规模以上收入项目（控制不超过 5 个）」）
是给你的指令，**成品里必须删掉**（`--drop-prefix` 或按前缀匹配删段）。
