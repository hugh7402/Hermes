# 作战图数据底盘：六张表的列定义

直接照抄建表。列名是页面读数的依据（`sheet_to_json` 按表头名取列），**改名/改顺序都会让图读空**，
只有标注「用户可加列」的地方才允许往右加。

---

## 1. 任务台账（用户主要改这张）

| 列 | 必填 | 说明 |
|---|---|---|
| 序号 | ✅ | 整数，可往下续编；页面按它排序 |
| 工作分类 | ✅ | 阶段名（如 商务推进/联合设计/平台建设/…）。**加行时必须填**，否则新任务挂到上一个分类底下 |
| 工作任务 | ✅ | 一句话，控制在 ~24 字内，长了甘特左侧会撑很高 |
| 所属系统 | ✅ | 下钻第二层的分组键。一条任务对应多个系统时用 ` / ` 分隔，**页面聚合只取第一个**，否则合计会重复计数 |
| 责任组 | ✅ | 必须与「组织架构」表的组名一致，否则责任分工汇总里出现孤立行 |
| 责任人 | ✅ | **填到人**（组长/实施推进人）。只有组名不算「责任到人」 |
| 执行成员 | | 组内分工、供应商投入，可写「联通 3 人、XX 4 人」 |
| 计划开始 / 计划完成 | ✅ | `YYYY-MM-DD`；周轴由这两列自动推，不需另行维护时间轴 |
| 工期(周) | 自动 | 由起止算，不要手填 |
| 计划进度% | 自动 | 页面上按日期算；Excel 里给 `MEDIAN(0,100,ROUND((TODAY()-开始)/工期*100,0))` 公式，方便不打开页面也能看 |
| 实际进度% | ✅ | 0–100 整数，不带 `%`。**空 = 未填报**，不等于 0；黄色底提示 PMO 填这一列 |
| 偏差 | 自动 | `实际 - 计划`；空时显示「未填报」，不要显示 0 |
| 状态 | ✅ | **只能**：`未开始` `进行中` `已完成` `已超期` `已暂停`。其他写法图上不认 |
| 关联运营指标主线 | | 取值等于指标表里「运营主线」的原文，用于把任务挂到成效指标上（抽屉里会展开三档目标值） |
| 关联建设项 | | 平台建设指标的序号，支持单号 `49`、列表 `49,62`、区间 `4-28` 三种写法 |
| 问题与风险 | | 自由文本，图上做 hover 提示 |
| 备注 | | 自由文本 |

## 2. 里程碑

| 列 | 说明 |
|---|---|
| 节点 | `M1`…，短代码，出现在甘特竖线的 tooltip |
| 目标日期 | `YYYY-MM-DD`，决定竖线落在哪一周 |
| 节点名称 | 如 系统初验 / 系统终验 / 全面推广 |
| 交付内容 | 该节点必须交出什么 |
| 验收标准 | 判定通过的量化条件 |
| 责任人 | 通常是 PMO 负责人 |
| 当前状态 | 同任务台账的状态词表 |

节点数量控制在 5–7 个。十几个节点会让顶部横条挤成一团，也失去“关键节点”的意义。

## 3. 组织架构

| 列 | 说明 |
|---|---|
| 部门/组 | 与任务台账的「责任组」同名（子组可用两个前导空格缩进表达层级） |
| 角色 | 组长 / 项目经理 / 云架构师 |
| 姓名 | 责任人姓名；原图是占位符（`XX（待定）`）就**照原文保留**，不要自己填一个 |
| 说明 | 人员构成：「67 人：A 9、B 15、C 4 …」，子项之和必须等于总人数 |

## 4. 运营成效指标（按节点给目标值）

| 列 | 说明 |
|---|---|
| 序号 / 运营主线 / 运营任务 | 主线是分组键；某行属于上一条主线时，主线列留空再由解析器向上填充 |
| 验收指标（建成要件） | 这段文字是评审对照的依据，**原文照录**，不要改写措辞 |
| 2026年底目标值 / 初验目标值 / 终验目标值 | 三个节点各占一列；**列名即口径**，改列名页面就读不到 |
| 当前完成情况 | PMO 填。空 = 未填报，驾驶舱指标看板单独统计填报率 |
| 需协同条件 / 依据条款/标准 / 验证方法 | 原样保留，评审会追到这三列 |

## 5. 平台建设指标（验收标准）

| 列 | 说明 |
|---|---|
| 序号 / 分类 / 板块 / 系统 / 子系统 | 层级；空行靠向上填充继承 |
| 建设内容 / 应用场景 | 摘要即可，图上只显示前 ~120 字 |
| 评价与验收标准 | 常是**合并单元格**（整段安全子系统共用一格）。读取要按 anchor 解析，写入不要写进非首行 |
| 当前完成情况 | PMO 填，空 = 未填报 |

## 6. 使用说明

两列：`项目` / `说明`。必须覆盖：

- 改哪个文件、改完怎么刷新（不用重新生成）
- 三个必改列（责任人、计划起止、当前进度%）
- 状态词表、进度写法、日期格式
- 能不能加行、加行时哪些列必须跟着填
- 哪些东西图上会自动算（超期、月份行、里程碑竖线、本周高亮）
- 这一版哪些有据可依、哪些是推断、哪些待补

## 状态 → 颜色/语义对照

| 状态 | 色 | 触发 |
|---|---|---|
| 已完成 | 绿 `#2E7D32` | 用户填 |
| 进行中 | 蓝 `#1565C0` | 用户填 |
| 未开始 | 灰 `#D9DFE6` | 用户填 / 默认 |
| 已超期 | 红 `#C62828` | 用户填，**或** 计划完成已过且未完成（唯一允许的自动判定） |
| 已暂停 | 橙 `#EF6C00` | 用户填 |

任务条 = 状态底色（整条计划期） + 浅色填充（宽度 = 进度%）。图例必须把这两层写清楚。
